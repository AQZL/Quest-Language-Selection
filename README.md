# FTB Quests Language Selector

Minecraft **1.21.1 / NeoForge** 的 FTB Quests 附属模组。任务书语言独立于 Minecraft 界面语言，按**存档 + 玩家 UUID**保存。

## 功能

- 玩家在当前存档第一次打开任务书时，在任务界面中央弹出「语言选择」。右键任务书、快捷键打开等入口均适用。
- 弹窗从下方滑入，语言选项直接显示；24 组世界文字分布在整个窗口背景区域（包括上、下和两侧），持续浮动和轻微旋转。使用独立的实时时间轴，入场结束、游戏暂停后仍继续漂浮。
- 点击“完成”后，文字从当前漂浮位置带初速度和重力快速下落。弹窗在约 0.16 秒内从上下压成细线，0.22 秒结束细线收尾，约 0.32 秒完成整个收场；不会重播入场或选项动画。点击弹窗外或按 Esc 不会关闭任务书或语言选择。
- 关闭时遮罩随动画淡出；语言同步只更新原界面的内容，保留章节、缩放与任务地图位置，避免收场后重建任务书导致的闪烁。延迟到达的语言同步同样使用原界面刷新。
- 窗口尺寸或 GUI 缩放变化时，语言选择弹窗会重新计算尺寸并保持居中，保留当前语言列表滚动位置。
- 列表来自当前 FTB Quests 任务目录下实际有效的 `lang/*.snbt` 文件，默认路径为 `config/ftbquests/quests/lang/`。
- 只有一个有效语言文件时自动使用该语言，不弹窗、不显示切换按钮；没有语言文件时保持 FTB Quests 原有行为。
- 多语言时，在任务书右下角设置按钮区域加入原版 Minecraft 地球图标，随时重新选择。
- 支持滚动语言列表。已知语言显示 Minecraft 自带的语言名称，自定义语言代码也可以显示和选择。
- 标题、提示和按钮文字使用 Minecraft 翻译键；选择界面跟随游戏界面语言，任务正文使用所选任务语言。
- 按钮、面板由 FTB UI 绘制，地球图标直接引用 Minecraft 的 `minecraft:icon/language`，不包含自绘图片。
- 语言选择弹窗固定使用 FTB Quests 自带的默认方格背景，不受 `ftb_quests_theme.txt` 中的全局或章节背景设置影响。

## 安装

把 `build/libs/ftbqlang-1.0.0.jar` 放入 `mods` 文件夹，替换旧版 JAR。不要安装 `-sources.jar`。

多人游戏需要**客户端和服务端都安装**本模组。单人游戏只需放入客户端 `mods`。

开发及构建使用以下依赖：

| 模组 | 版本 |
| --- | --- |
| Minecraft | 1.21.1 |
| NeoForge | 21.1.213 或更新的 21.1.x |
| FTB Quests | 2101.1.27 |
| FTB Library | 2101.1.31 |
| FTB Teams | 2101.1.9 |
| Architectury API | 13.0.8 |

这是 NeoForge 版本，不能直接放入 Fabric 或旧版 Forge 实例。

## 语言文件

例如：

```text
.minecraft/
  config/ftbquests/quests/lang/
    en_us.snbt
    zh_cn.snbt
    ja_jp.snbt
```

文件内容沿用 FTB Quests 自己的任务翻译格式，本模组不自动翻译任务。无法解析的文件、子目录、备份文件不会被当作有效语言。FTB 自动生成的内存回退表不计入语言数量。

多人服务器使用**服务器的**任务语言文件，无需每位玩家在本地复制。重新打开任务书或点击地球按钮会重新扫描文件。缺失译文沿用 FTB Quests 的回退机制。

## 存档记录

数据位于 `<存档>/data/ftbqlang_preferences.dat`，以玩家 UUID 分别记录所选语言和是否提示过。同一存档重新登录不会重复自动弹窗；新存档、新玩家独立提示。关闭首次弹窗也算已提示，可以随后点击地球按钮更改。

如果首次进入时只有一个语言文件，不消耗首次多语言提示状态；之后加入更多语言并重新进入存档时，仍可进行首次选择。已选语言被移除时，依次使用游戏语言、英语、列表中的第一个语言。

## 开发

需要 JDK 21：

```powershell
.\gradlew.bat build
.\gradlew.bat runClient
```

源码参考：[FTB Quests bugfix/1.21/disable-blur](https://github.com/FTBTeam/FTB-Quests/tree/bugfix/1.21/disable-blur)。编译接口以发布版 2101.1.27 为准，客户端 Mixin 接入任务语言、界面刷新、关闭按键和右下角按钮列表；服务端不加载客户端界面类。

## 游戏内验收

1. 准备 `en_us.snbt`、`zh_cn.snbt` 和对应的任务翻译，进入新存档，右键任务书，检查居中标题和语言列表。
2. 选择语言，检查章节名、任务标题、描述刷新，Minecraft 菜单语言保持原设置。
3. 关闭再打开任务书、退出再进入同一存档，确认不重复弹窗且语言保留。
4. 点击右下角地球切换语言；调整窗口和 GUI 缩放，检查列表和滚动区域。
5. 换新存档或另一个玩家，确认分别提示。
6. 仅保留一个语言文件并重新进入，确认没有弹窗或地球按钮。
7. 双人服务器分别选择不同语言，确认互不影响，重新连接后各自恢复。
8. 保持语言窗口打开至少一分钟，确认整个背景区域的文字仍在移动；点击完成检查快速压缩、文字下坠以及任务内容刷新。
9. 切换到非首个章节并移动、缩放任务地图，选择语言后立即点击完成，检查收场后没有空白闪帧或位置跳动；多人服务器下也检查延迟语言同步不会重新打开界面。不切换语言直接点击完成，同样应平滑返回。
